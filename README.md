# رقيب — React Native (أندرويد)

تطبيق أندرويد أصلي لإدارة المخزون الدوائي، مبني بـ React Native 0.88.1 + TypeScript. لا يستخدم WebView ويعمل بالكامل دون اتصال بالإنترنت.

## التشغيل السريع

```bash
npm install
npm run android
```

راجع [`docs/BUILD.md`](docs/BUILD.md) لبناء Release APK/AAB، و[`docs/DESIGN.md`](docs/DESIGN.md) لنظام التصميم.

## الميزات

- 30 يوماً تجربة من أول تشغيل، ثم ترخيص موقّع Ed25519 مرتبط ببصمة الجهاز.
- كلمة تثبيت ونمط قفل محفوظان كتجزئة PBKDF2-HMAC-SHA256 مع ملح عشوائي (210,000 دورة).
- قفل تدريجي بعد المحاولات الخاطئة (30/60/120/300 ثانية).
- إدارة المنتجات والتشغيلات (CRUD) مع بحث وفلاتر وترتيب حسب أقرب صلاحية.
- تنبيهات الصلاحية: جيد (>90) · قريب (31–90) · حرج (0–30) · منتهي (<0).
- لوحة تحكم بإحصاءات فورية، ونسخ احتياطي/استيراد JSON، ومركز مزامنة اختياري.
- عربية RTL كاملة + وضع داكن + تصميم عالي الجودة.

## ملاحظة أمنية

لا توجد كلمة مرور أو مفتاح ترخيص مكتوب داخل الحزمة. مفتاح الترخيص العام فقط مضمّن (ليس سراً). لتوليد مفاتيحك راجع `scripts/generate-keys.mjs`.

## الحالة

المشروع جاهز للبناء. إذا احتجت دعماً لتنسيق «KLENCODE» تحديداً، أرسل مواصفات المنصة لإضافة ملفاتها.
